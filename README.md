# رحلة في وطننا العربي

ألعاب تفاعلية لوحدة «وطننا العربي» (الدراسات الاجتماعية — مصر) للأطفال من ٨ إلى ١٦ سنة:
خرائط حقيقية، بطاقات، ترتيب، مطابقة، اختبارات، وصوت مصري طبيعي.

**الموقع:** https://asem-saad.github.io/egypt-edu/

- يدخل ولي الأمر بحسابه، ويختار كل طفل اسمه ورقمه السري.
- يُحفظ التقدم على الجهاز ويتزامن مع الحساب على الإنترنت.
- يمكن للمعلّم إنشاء فصل بكود ومتابعة نتائج طلابه.

Interactive Arabic learning games for the Egyptian social-studies unit «وطننا العربي».
Static site (HTML/CSS/JS) + Supabase for accounts and progress.
